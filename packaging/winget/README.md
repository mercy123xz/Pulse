# winget

The manifests that list Pulse in winget (`winget install mercy123xz.Pulse`). They are sent to
[microsoft/winget-pkgs](https://github.com/microsoft/winget-pkgs) as a pull request, at
`manifests/m/mercy123xz/Pulse/<version>/`. A new Pulse version needs a new folder with the new
version, installer URL and SHA256 (GitHub shows it on the release asset as `digest`).
